# ⚛️ React Lab - Multi-Version Learning Environment

Entorno de aprendizaje multi-versión para React 16, 17, 18 y 19 con TypeScript.

## 🎯 **Propósito**

Experimentar y comparar diferentes versiones de React para entender:
- Evolución de APIs y características
- Diferencias de comportamiento entre versiones
- Patrones de migración
- Performance y herramientas

## 🏗️ **Versiones Incluidas**

| Versión | Puerto | Características Principales |
|---------|--------|---------------------------|
| **React 16.8** | 3016 | Hooks Foundation, Class Components |
| **React 17.0** | 3017 | JSX Transform, Event Delegation |
| **React 18.3** | 3018 | Concurrent Features, Suspense |
| **React 19.1** | 3019 | Server Components, Actions |

## 🚀 **Instalación Rápida**

```bash
# 1. Clonar repositorio
git clone <repo-url> react-lab
cd react-lab

# 2. Instalar todas las dependencias
npm run install:all

# 3. Ejecutar selector de versión
npm run dev

```
